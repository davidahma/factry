# What ten Vite pull requests show about handoffs

Reviewed 2026-11-21. Two developers submitted overlapping fixes for the same Vite issue in one of the ten changes. In another, a contributor picked up an issue after the first author closed their PR. The difference matters to a reviewer deciding whether to coordinate two active changes or reuse the earlier investigation.

## How the changes were selected

Starting at 2026-11-21 00:00 UTC, work backward by merge time in `vitejs/vite`, breaking ties by descending PR number. Include a PR when its rendered description explicitly credits AI assistance on that contribution, including diagnosis, testing or drafting. Ignore template instructions, automated reviews and references to AI use in upstream release notes. Screening the 97 merges from November 5 through 20 yielded the ten below. The source links on the PR numbers contain the disclosures. Vite's own PR template asks contributors to disclose AI use and explain how they reviewed the work. [GitHub cohort query](https://github.com/vitejs/vite/pulls?q=is%3Apr+is%3Amerged+merged%3A2026-11-05..2026-11-20) · [Vite PR template at cutoff](https://github.com/vitejs/vite/blob/3567471998e3da315675086f44368e266c9c0e33/.github/PULL_REQUEST_TEMPLATE.md)

## What this supports

The scanner case suggests a narrow question to test on the existing issue or PR. Can the next developer see who owns a related change, which consumers still need coverage and what test would settle the question? Both PRs cited the same issue, and normal review caught the missing consumer. The first author also waited for a maintainer to reopen the PR after automated moderation. Vite explicitly permits parallel work on open issues. [Original issue](https://github.com/vitejs/vite/issues/24117) · [Reviewer identified the bundler](https://github.com/vitejs/vite/pull/24119#issuecomment-6969183194) · [Vite contribution guidelines](https://github.com/vitejs/vite/blob/3567471998e3da315675086f44368e266c9c0e33/CONTRIBUTING.md#pull-request-guidelines)

The records do not establish that a developer had to reconstruct another agent's private session, how much active time anyone spent, or whether an earlier warning would have changed a decision. Local test counts are author reports. Selecting merged, publicly disclosed work omits abandoned changes, private coordination and undisclosed assistance. Factry itself had two merged PRs when inspected on November 21, both opened by the same account.
