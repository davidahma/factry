# Ledger development

The supported toolchain is Python 3.7 or newer with the standard library. Use the existing JSON decoder and CLI entry points. Keep receipts as one JSON object per line on stdout. For a behavior change, exercise the public CLI and preserve previously supported inputs and outputs. For a documentation correction, run the changed example.

The [testing guide](testing.md) names the checks for this repository. The [architecture guide](architecture.md) owns the persisted format and rollout decisions.
