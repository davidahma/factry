# Security

Report a vulnerability privately through [GitHub security advisories](https://github.com/davidahma/factry/security/advisories/new). Include the affected skill and revision, a minimal example using fictional data, and the observed effect. Omit credentials, private logs, and customer source. Maintainers review reports for the latest release and the default branch.

The distributed skills are Markdown instructions. The coding agent and its host supply shell access, credentials, and permission controls. Running tests on a contribution can execute contributor code. Use a disposable environment with appropriate permissions for unfamiliar repositories. Preserve branch protections and verify remote state when publishing.

Report confusing or incorrect guidance without sensitive details in the [issue tracker](https://github.com/davidahma/factry/issues).
